## Overview

EduCare is a web application designed for teachers and refugee parents to improve communication and help parents become more involved in their children's educational development. Developed for the "Web" module, the project applies knowledge from web development and research courses to create a functioning website for refugees.

[View Live Demo →](https://educaregruppef.onrender.com/)

## Challenge

Refugee families face significant communication barriers in educational settings. Teachers struggle to share important information about children's progress, while parents feel excluded from their children's education due to language limitations and unfamiliarity with the German school system. Traditional communication methods (paper notes, parent-teacher meetings) fail to bridge these gaps effectively.

## Approach

### Research & User Interviews
- Conducted interviews with teachers working with refugee students
- Spoke with refugee parents about their experiences navigating the school system
- Identified key pain points: language barriers, unfamiliar processes, lack of timely information

### Feature Development
- **Calendar System**: Shared calendar for school events, appointments, and important dates
- **Messaging**: Direct communication channel between teachers and parents
- **Progress Tracking**: Visual indicators for student performance and development
- **Document Sharing**: Easy upload and access to important school documents

### Team Collaboration
- Worked in agile team of 5 developers
- Used Git for version control and collaboration
- Conducted weekly sprints and code reviews
- Divided responsibilities: Frontend, Backend, Research, Testing

## Technical Implementation

- Built with React.js for dynamic, responsive interface
- Implemented calendar functionality for event management
- Created messaging system for teacher-parent communication
- Designed intuitive navigation for non-technical users
- Ensured responsive design for mobile and desktop access

## Results

- Successfully delivered working web application within one semester
- Positive feedback from teachers and parents during testing phase
- Reduced communication barriers through digital platform
- Increased parent engagement in children's education
- Applied academic knowledge to real-world social impact project

## Key Learnings

This project taught me the importance of inclusive design and the impact technology can have on vulnerable communities. Working in a team environment, I learned to balance technical implementation with user needs, navigate git workflows for collaborative development, and apply academic concepts to practical social challenges. The experience reinforced that good design isn't just about aesthetics—it's about accessibility, empathy, and solving real problems for real people.
